# 文稿修订工作流

修订的目标，是让原稿更准确、更清楚、更契合读者需要，同时使立意、文脉与表达彼此协调。动笔之前先诊断，落笔之后再核对；修改范围与信息权限始终相称。

## 一、辨明任务、作者与读者

先确认用户要求完成的动作，以及最终文本的用途。区分指令所描述的工作与正文所讨论的主题：删改、替换、压缩、重组等要求，应直接落实到目标内容；只有任务本身要求分析某项指令或制定规范时，才将其写成论述对象。

随后辨明文本由谁发言、面向谁、承担什么功能。对话回答服务当前交流，独立文稿服务预定读者，协作说明服务委托者或审校人员。不同受众需要不同的信息深度、叙述视角与语气。大纲、批注、检索记录和修改理由留在协作记录中，成稿只保留读者理解主题所需的内容。

## 二、诊断立意与文脉

修订前，先用简洁的一句话概括文本的核心问题、主要判断或叙事主线，再检查材料与主线的关系。

| 诊断维度 | 需要辨明的问题 | 修订方向 |
|---|---|---|
| 立意 | 文本最终要说明什么、解释什么或促成什么 | 明确核心判断，调整材料取舍 |
| 受众 | 读者已有何种知识，需要获得什么 | 补足必要背景，控制术语与解释深度 |
| 结构 | 信息次序是否符合事理 | 调整章节、段落及论据位置 |
| 论证 | 观点、依据、解释与结论是否衔接 | 意合顺畅，剔除多余虚词，修正跳跃推理 |
| 详略 | 哪些内容支撑主线，哪些内容分散注意 | 压缩枝节，展开关键依据 |
| 语气 | 作者立场与文体要求是否一致 | 校准确定程度、礼貌程度与表达力度 |

批注意图通常描述阅读感受或问题症状，未必直接给出改法。将其转化为正文动作时，先确认问题落在哪一层：

| 批注意图 | 应检查的实际问题 | 对应的修订动作 |
|---|---|---|
| 过渡突兀 | 前后段之间是否缺少必要的因果、条件或对象承接 | 补足材料支持的事理环节；依靠内在线索推进，少用生硬连接词 |
| 重点不突出 | 核心对象是否埋在修饰语或次要信息之后 | 将关键对象或判断移至主句，调整信息先后 |
| 语气过满 | 结论是否超出证据、样本或适用条件 | 有依据地收紧判断范围；通过限定范围自然藏拙，不滥加防御性免责 |
| 内容冗余 | 是否重复解释同一事实或结论 | 合并同义信息，保留最能承担论证功能的表达 |
| 表达生硬 | 是否存在名词化套壳、长定语、指代重复或显性连接词过密 | 重建主谓关系，以强动词带动句意，拆分句群顺畅承接 |
| 删除某项内容 | 被删信息是否影响剩余句子的语法或论证成立 | 直接移除目标内容，自然缝合语脉；必要时指出实质影响 |

## 三、让修改幅度与问题层级相称

**字词级调整**适用于术语不统一、动词失准、语气轻重不当或局部重复。此时保留原句骨架，处理明确病灶。

**句群级重组**适用于句子承载过多条件、因果关系倒置、删减后语脉失衡，或新增信息无法自然嵌入原句。先拆开原有结构，再按对象、动作、条件和结果重排。

**段落级调整**适用于中心意思不清、论据与判断脱节、多个段落反复表达同一内容。重新确立段落职责，让背景、论据、解释与结论各归其位。

**篇章级重构**适用于论述顺序失衡、章节功能重叠或读者无法辨认主线。先明确全文要回答的问题，再安排章节关系；重组时保留仍然有效的事实、证据、引用与限制。

修订范围以解决问题为限。局部批注通常对应局部修改；若更大范围的调整确有必要，应依据任务授权执行，并在交付说明中简要交代。

## 四、按信息性质校准编辑幅度

许多待修文本经过多轮转述、自动生成或非专业整理，信息边界未必处处清晰。机械要求每句话与原文逐字对应，容易把编辑限制在表面替换；更合宜的做法，是先辨认必须守住的事实，再主动改善其余表达。

| 信息性质 | 编辑空间 | 判断依据 |
|---|---|---|
| 核心事实 | 严格约束 | 是否涉及人物、时间、数量、关键事件、结果、责任或重大决策条件 |
| 一般表述 | 可以灵活调整 | 是否属于概括、评价、日常描述或语义有弹性的表达 |
| 具体事实 | 谨慎增补 | 是否新增精确数据、参数、身份、时间、机制、成果或可核验细节 |
| 合理推论 | 视语境使用 | 是否由上下文自然支持，是否会被读者误认为已验证事实 |

**核心事实从严，一般表述从宽，具体事实慎增。** 对一般表述，可以归纳其含义、梳理逻辑连接、调整语气强弱，或将松散描述改写成更完整的判断。语义重构属于编辑职责。不要因为原文没有逐字写出某个过渡，就拒绝做出显而易见、低风险的自然衔接。

具体事实则需要材料支持。精确数字、日期、人物身份、实验参数、性能指标、因果机制、已完成的行动与成果，都可能被读者视为可核验事实；没有依据时，不应自行补造。推论可以进入正文，其确定程度应与依据相称。一般性解释自然展开，重要推断则适度标明性质。

任务授权决定编辑幅度。用户要求逐字校对时，尊重其范围；用户要求润色、改写或重构时，主动解决表达与组织问题。原文存在明显错误、逻辑断裂或重要歧义时，优先修正；唯有不同解释会实质改变事实、立场或结论时，才需向用户澄清。

## 五、删减、增补与缝合

删除内容后，先判断剩余部分能否独立成立。若语法完整、语意清楚，直接收束；若句法失衡，可调整语序、合并相邻句子或恢复必要的主谓关系。句子是否足够长，不是补造信息的理由。

当被删除内容构成结论成立的必要条件、安全警告或关键限制时，应指出删改将造成的实质后果，并提出弱化表达、调整位置或明确限定适用范围的方案。

新增内容进入正文之前，先判断它与既有信息的关系：是补充条件、解释原因、提供证据、指出例外，还是引出下一层问题。新增信息改变原句重心时，拆分句子；解释前文时，靠近所解释的判断；构成限制时，紧随适用范围，或通过正向定界含蓄带出；开启新的论述层次时，另起段落。

## 六、修订交付前核对

- 用户要求执行的动作是否直接落实到目标内容？
- 作者位置、最终读者与文本用途是否明确协调？
- 核心立意是否清楚，材料是否紧扣主线？
- 修改范围是否与授权相称，健康段落是否得到保留？
- 核心事实是否准确，一般表述是否充分改善？
- 新增的具体事实是否有依据，是否避免了凭空捏造？
- 是否避免了防御性过度免责与虚空抬杠？是否懂得正向定界与含蓄藏拙？
- 逻辑是否融入句法骨骼，是否避免了显性连接词通篇堆叠？
- 是否误删结论成立所需的关键条件、限制或安全信息？
- 交付物是否干净，彻底去除了指令复述、批注残留与答题式痕迹？

交付时以完整修订稿为主体。唯有在用户需要审阅修改依据，或改动涉及重大事实判断时，才另附简明说明。
